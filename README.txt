# A.R Bambang POS — GitHub Pages upload

Upload all files in this folder to the root of your GitHub repository (or the `ARBambang` folder if that is the folder configured for your site).

Files:
- `index.html` — the supplied POS app (contents preserved)
- `styles.css` — existing app styles
- `manifest.json` — PWA install settings
- `service-worker.js` — offline cache
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — generated from the logo supplied for this upload

For GitHub Pages, open repository **Settings → Pages** and publish from the branch/folder where these files were uploaded.
